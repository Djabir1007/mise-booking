## Запуск проекта

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Djabir1007/mise-booking.git
```

2. Перейдите в папку проекта:

```bash
cd mise-booking
```

3. Установите зависимости:

```bash
npm install
```

4. Запустите проект в режиме разработки:

```bash
npm run dev
```

5. Откройте в браузере:

```text
http://localhost:3000
```

## Принятые решения

Для формы использованы React Hook Form и Zod, чтобы разделить работу с состоянием формы и валидацию. Состояние процесса бронирования хранится в отдельном родительском компоненте и переключается между `idle`, `loading` и `success`.
Компоненты формы и экрана подтверждения разделены, чтобы упростить структуру и логику приложения. Для стилизации использованы CSS Modules вместо SCSS, так как для небольшого тестового проекта этого достаточно и не требуется дополнительная настройка препроцессора.
Для улучшения пользовательского опыта добавлена валидация полей при потере фокуса и плавная анимация перехода между формой и экраном подтверждения.

Проект реализован на Next.js с использованием App Router.
